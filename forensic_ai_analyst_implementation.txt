Run the forensic research workflow for date1 == 2021-05-16 and date2 == 2026-05-16.

Use:
- forensic_ai_analyst_instructions.txt for row-level research rules, evidence requirements,
  field definitions, and .researched output schema.
- forensic_research_batches.py for batch discovery, ordering, validation, and final
  concatenation.

Required workflow:

1. Prepare the batch workflow:

   python forensic_research_batches.py prepare <date1> <date2>

2. Repeat until no batch remains:

   a. Get the current batch:

      python forensic_research_batches.py next <date1> <date2>

   b. Research only the returned batch CSV.

   c. For that batch, identify rows where needs_review == true.

   d. Write:

      <batch_csv_path>.researched

   e. Validate the current batch:

      python forensic_research_batches.py validate-one <batch_csv_path>

   f. Do not move to the next batch until validate-one passes.

3. Finalize after all batches validate:

   python forensic_research_batches.py finalize <date1> <date2>

Strict rules:
- process exactly one batch CSV at a time
- read only the current batch CSV during that batch's research pass
- perform fresh external research for only the current batch
- do not research rows from multiple batch files in the same pass
- do not reuse conclusions from prior batches
- do not draft a later .researched file before the current file validates
- do not modify source CSV files
- if any command reports an error, stop and fix only the current batch

At the start of each batch, explicitly reset context:

"Beginning independent research for <batch_csv_path>. No conclusions from prior files are being used."

When finalize completes, the final output must be:

inputs/real_world_events.<date1>.<date2>.csv
